# FF POS 스마트 관리 시스템 설치 및 실행 가이드

본 문서는 GitHub에 업로드된 프로젝트 소스코드를 다운로드하여 설치하고, PC 및 모바일(스마트폰) 환경에서 시스템을 실행하는 방법을 안내합니다.

---

## 1. 사전 준비 (Prerequisites)
프로젝트를 실행하기 위해 컴퓨터에 **Node.js**가 설치되어 있어야 합니다.
* **Node.js 다운로드 및 설치:** [https://nodejs.org/ko/](https://nodejs.org/ko/) (LTS 버전 권장)

---

## 2. 프로젝트 다운로드 (Download)
1. 본 프로젝트의 **GitHub 저장소 링크**로 접속합니다.
   * 저장소 링크: `[본인의 깃허브 주소를 여기에 적으세요]`
2. 초록색 **[ <> Code ]** 버튼을 클릭한 후, **[Download ZIP]**을 선택하여 파일을 다운로드합니다.
3. 다운로드 받은 ZIP 파일의 압축을 해제합니다.

---

## 3. 필수 패키지 설치 (Install Dependencies)
Node.js 프로젝트 실행에 필요한 외부 라이브러리(`package.json`에 정의됨)를 설치해야 합니다.

1. 압축을 해제한 프로젝트 폴더(예: `FF-POS-System-main`)를 엽니다.
2. 폴더 빈 공간의 위쪽 **주소창(경로창)을 클릭**하고 `cmd`를 입력한 후 엔터(Enter)를 칩니다. (까만색 명령 프롬프트 창이 열립니다.)
3. 열린 cmd 창에 아래 명령어를 입력하고 엔터를 칩니다.
   ```bash
   npm install
   ```
4. 설치가 완료되면 프로젝트 폴더 내에 `node_modules` 폴더가 자동으로 생성됩니다.

---

## 4. 서버 실행 (Run Server)
패키지 설치가 끝난 cmd 창에서 바로 아래 명령어를 입력하여 서버를 가동합니다.
```bash
node server.js
```
* 정상적으로 실행되면 **"서버가 포트 3000에서 실행 중입니다."** 와 **"DB 연결 성공"** 이라는 메시지가 출력됩니다.
* **주의:** 시스템을 사용하는 동안 이 cmd 창을 끄면 안 됩니다.

---

## 5. PC 관리자 화면 접속 (Localhost)
1. 사용 중인 웹 브라우저(Chrome 권장)를 엽니다.
2. 주소창에 아래 주소를 입력하고 접속합니다.
   ```text
   http://localhost:3000
   ```
3. 대시보드 창이 뜨면 PC에서의 접속이 성공한 것입니다.

---

## 6. 스마트폰(모바일) 스캐너 접속 (Ngrok 활용)
스마트폰의 카메라를 바코드 스캐너로 활용하기 위해서는 외부 접속을 허용하는 **ngrok** 프로그램이 필요합니다.

### 6-1. ngrok 다운로드 및 설정
1. **ngrok 공식 사이트**([https://ngrok.com/](https://ngrok.com/))에 접속하여 회원가입 및 로그인을 합니다.
2. 운영체제(Windows)에 맞는 ngrok 압축 파일을 다운로드하고 압축을 풉니다.
3. 압축을 푼 폴더 안에 있는 `ngrok.exe` 파일을 실행합니다.
4. ngrok 홈페이지 대시보드의 **[Your Authtoken]** 메뉴에서 토큰 복사 후, 열려있는 ngrok 창에 붙여넣고 엔터를 칩니다. (초기 1회만 필요)

### 6-2. 포트포워딩 및 모바일 접속
1. `ngrok.exe`가 실행된 까만 창에 아래 명령어를 입력하고 엔터를 칩니다.
   ```bash
   ngrok http 3000
   ```
2. 화면에 출력된 정보 중 **`Forwarding`** 옆에 있는 **`https://~~~.ngrok-free.app`** 형식의 주소를 복사합니다.
3. 해당 주소를 카카오톡 "나에게 보내기" 등을 통해 **자신의 스마트폰으로 전송**합니다.
4. 스마트폰에서 해당 링크를 클릭하여 접속하면, 스마트폰 카메라를 활용한 현장 바코드 스캔 기능을 사용할 수 있습니다.
